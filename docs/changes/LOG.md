# Applied changes to frozen files

One line per batch (`testing.md` 7.4): the date, what was applied, and what every owner has to do.

- 2026-10-13, integrator fixes before the second node stage (no change request: the first node stage reported these). Promoted from `select` into core (`testing.md` 7.5): `ops.smooth` with its steps `ops.scale`, `ops.fit`, `ops.restore`, `ops.shadow`, `ops.occlusion` (`engine.md` section 5), and the second-order border of `slopeAt` (`engine.md` 3.8); new core library `convert` (`engine.md` 3.9). `select` and `filter/high-pass`, `sharpen`, `slope-warp`, `slope-blur` and `warp` use them; `select/_scale.ts` and the library `selectTerrain` are gone. Every owner: smooth with `ops.smooth` wherever the result is taken from the source or differentiated, and with `ops.blur` only where the blur is the result; take shadows and occlusion from the ops; read a colour as a height with `convert_luma`; do not call the WGSL builtin `tanh` (lint `no-tanh`). Pictures: `orogen render --masked` is now `--connected` and also connects optional inputs, the plain variant leaves them unconnected, terrain 0 is `generate/eroded-noise`, and `orogen gallery` writes one page per category (`testing.md` 2.4, 8.6). `nodes.md` is read by `tests/unit/catalog.test.ts`: a category with registered nodes must hold every node its table lists, and a node beyond them needs a row under `### Added by owners`. `visibleWhen.equals` takes a list (`engine.md` 4.3). The default project is 4032 m by 1008 m (`runtime.md` 4.2).
