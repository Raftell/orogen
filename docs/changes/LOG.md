One line per batch (`testing.md` 7.4): the date, what was applied, and what every owner has to do.

- 2026-10-13, integrator fixes before the second node stage (no change request: the first node stage reported these). Promoted from `select` into core (`testing.md` 7.5): `ops.smooth` with its steps `ops.scale`, `ops.fit`, `ops.restore`, `ops.shadow`, `ops.occlusion` (`engine.md` section 5), and the second-order border of `slopeAt` (`engine.md` 3.8); new core library `convert` (`engine.md` 3.9). `select` and `filter/high-pass`, `sharpen`, `slope-warp`, `slope-blur` and `warp` use them; `select/_scale.ts` and the library `selectTerrain` are gone.
